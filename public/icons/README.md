# Iconos de ImpostorApp

Los iconos parten de `icon-source.png`, generado para ImpostorApp como una marca
cuadrada sin texto: una media mascara teatral integrada en un bocadillo de
conversacion, con fondo carbon, figura esmeralda y acento ambar. La composicion
mantiene el simbolo dentro de la zona segura central para admitir recortes
maskable.

- `icon-192.png`: icono PWA de 192 x 192 px.
- `icon-512.png`: icono PWA y maskable de 512 x 512 px.
- `apple-touch-icon.png`: icono Apple touch de 180 x 180 px.
- `icon-source.png`: fuente raster de 1024 x 1024 px.

Las variantes se exportaron desde la fuente con Sharp, en PNG RGB y sin cambiar
la composicion.
